# Luna 생성 안정성 보완 결과

## 적용 범위

- 내부 경로 노출 차단: 알 수 없는 AI 오류는 원문을 반환하지 않는다. macOS·임시 디렉터리·Windows 드라이브 경로를 공통 오류 필터에서 차단한다. 코드가 만든 품질 실패와 연결 설정 오류는 안내를 유지한다.
- 분량: 선택된 근거가 충분할 때 짧게 500자, 보통 1,000자, 길게 2,000자 미만이면 보정한다. 근거가 부족하면 최소 분량을 강제하지 않는다. 기존 최대 분량 검사는 유지한다.
- 진행 표시: 근거 확인 / 작성 / 검토 / 보정 상태를 전달하고, 대기 중 5초마다 상태를 전송한다. 검토 전 초안은 노출하지 않는다.
- 취소: 스트림 종료 시 작업에 취소 신호를 보내고 다음 AI 호출을 차단한다. 이미 공급자에게 보낸 요청을 소급 취소하거나 사용량을 되돌리지는 않는다. 응답이 돌아오면 폐기하며 요청별 제한은 최대 60초다.
- 실제 UI 연결: 텍스트 및 일반 단일 YouTube 생성은 스트림 경로를 사용한다. 일반 웹 URL·다중 URL·에이전트 모드는 기존 경로를 유지한다. 진행 중인 스트림에는 공통 진행·취소 안내를 표시한다.
- 중간 서버가 실시간 응답을 모아서 보내지 않도록 `Cache-Control: no-cache, no-transform`을 적용했다.
- 캐시 키 v4: 이전 검사 결과를 재사용하지 않되 기존 캐시와 노트는 삭제하지 않는다.

## 검증

- 백엔드 전체: **4,751 passed, 5 skipped, 32 subtests passed**. 외부 라이브러리 사용 중단 예정 경고 2건은 기존 사항이다.
- 프론트엔드 전체: **360 passed / 52 files**. TypeScript 및 Next.js 배포용 빌드 통과.
- 새 검사: 오류 원문·경로 차단, 충분한 근거의 최소 분량 보정, 짧은 원문 부풀리기 방지, 진행 이벤트, 보정 실패 시 초안 비노출, 공급자 응답 대기 중 연결 종료 후 추가 호출 중단.
- 실제 Luna 스트림 API: 상태 이벤트 후 본문·최종 결과 수신, 18초, 총 2,762토큰의 한국어 요약 사례 성공.
- 별도 로컬 브라우저(127.0.0.1:3002)와 테스트 백엔드(5001)로 텍스트 입력부터 생성 완료까지 확인했다. 인증·계정 저장은 테스트 대역, AI는 실제 로컬 CLIProxyAPI의 Luna를 사용했다. 운영 로그인·저장 검증을 의미하지 않는다.
- 브라우저에서 약 4초 후 작성, 이후 검토 상태가 실제로 바뀌는 것을 관찰했다. 검토 전 본문 비노출, 완료 결과 표시, 오류 화면 없음 확인.
- 실제 취소 버튼 클릭 후 입력란 활성화·입력 보존·진행 안내 종료 확인. 추가 AI 호출 차단은 자동 테스트로 검증했다.
- 브라우저 검증에서 일반 요청 경로에 연결돼 있던 입력 버튼과 도움말 버튼에 가려진 취소 안내를 발견해 함께 수정했다.

## 남은 경계

앱 전체의 무결함을 보장하는 검사는 아니다. 일반 웹 URL·다중 생성의 실시간 취소, 운영 인증·저장, 모든 입력 파일·언어·스타일 조합은 이번 실검증에 포함하지 않았다. 같은 모델의 독립 검토도 사실성을 보장하지 않는다. 운영 배포와 원격 저장소 반영은 하지 않았다.
