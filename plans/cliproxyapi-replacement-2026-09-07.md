- 세 언어 화면·모델 선택·배포/로그인/상태 검사·README/AGENTS를 갱신했다.

## 보존한 상태

- 기존 결과·노트·사용량 기록과 ChatMock/Codex 인증 파일·볼륨을 삭제하거나 변환하지 않았다.
- 과거 모델 선택은 지원되는 동일 모델만 메모리에서 연결하며, 미지원 선택은 GPT-5.5로 표시한다.
- 사용자가 직접 모델을 선택하기 전에는 기존 저장 설정을 덮어쓰지 않는다.
- 새 Docker 인증 볼륨만 사용한다. 관리 API/화면은 비활성화하고 호스트 포트는 로컬로 제한한다.
- 실제 `.env`와 운영 비밀 설정은 수정하지 않았다. 운영 서버 전환과 계정 로그인은 아직 수행하지 않았다.
