# 콘텐츠 생성 테스트 플랜

## 개요
- **앱 URL**: http://localhost:5001
- **seed 파일**: seed.spec.ts
- **테스트 파일**: tests/content-generation/

## 테스트 케이스

### Suite 1: AI 프로바이더 및 모델 선택

#### TC-1.1: 프로바이더 선택
**Steps:**
1. 프로바이더 드롭다운 클릭
2. 사용 가능한 프로바이더 선택 (Gemini, DeepSeek 등)

**Expected:**
- 선택한 프로바이더가 표시됨
- 해당 프로바이더의 모델 목록 로드

#### TC-1.2: 모델 선택
**Steps:**
1. 프로바이더 선택 후 모델 드롭다운 클릭
2. 모델 선택

**Expected:**
- 선택한 모델이 표시됨

### Suite 2: 스타일 선택

#### TC-2.1: 스타일 카드 선택
**Steps:**
1. 스타일 카드 섹션에서 카드 클릭

**Expected:**
- 선택된 카드에 하이라이트 표시
- 이전 선택 해제

#### TC-2.2: 여러 스타일 순회
**Steps:**
1. 각 스타일 카드를 순서대로 클릭

**Expected:**
- 항상 하나의 스타일만 선택됨

### Suite 3: 모디파이어 설정

#### TC-3.1: 길이 모디파이어
**Steps:**
1. 길이 옵션 (짧게/보통/길게) 중 하나 선택

**Expected:**
- 선택된 옵션 하이라이트

#### TC-3.2: 톤 모디파이어
**Steps:**
1. 톤 옵션 (친근/전문/유머) 중 하나 선택

**Expected:**
- 선택된 옵션 하이라이트

#### TC-3.3: 이모지 모디파이어
**Steps:**
1. 이모지 사용/미사용 선택

**Expected:**
- 선택 상태 반영

### Suite 4: 콘텐츠 생성 실행

#### TC-4.1: 생성 버튼 비활성화 상태
**Steps:**
1. URL 없이 생성 버튼 확인

**Expected:**
- 버튼 비활성화 또는 경고

#### TC-4.2: 생성 실행 (Mock)
**Steps:**
1. 유효한 URL 추가
2. 프로바이더/모델 선택
3. 스타일 선택
4. 생성 버튼 클릭

**Expected:**
- 로딩 스피너 표시
- 진행 상태 업데이트
- 결과 패널에 생성된 콘텐츠 표시

#### TC-4.3: 생성 중 취소
**Steps:**
1. 생성 실행 후 취소 버튼 클릭 (있는 경우)

**Expected:**
- 생성 중단
- UI 원상복구
