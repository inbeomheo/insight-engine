# 히스토리 및 사용량 패널 테스트 플랜

## 개요
- **앱 URL**: http://localhost:5001
- **seed 파일**: seed.spec.ts
- **테스트 파일**: tests/history-usage/

## 테스트 케이스

### Suite 1: 사이드바 네비게이션

#### TC-1.1: 대시보드 탭
**Steps:**
1. 사이드바의 대시보드 아이콘 클릭

**Expected:**
- 대시보드 패널 활성화
- 아이콘 하이라이트

#### TC-1.2: 히스토리 탭
**Steps:**
1. 사이드바의 히스토리 아이콘 클릭

**Expected:**
- 히스토리 패널 표시
- 이전 생성 기록 목록

#### TC-1.3: 사용량 탭
**Steps:**
1. 사이드바의 사용량 아이콘 클릭

**Expected:**
- 사용량 패널 표시
- 사용량 통계 정보

### Suite 2: 히스토리 패널

#### TC-2.1: 히스토리 목록 표시
**Steps:**
1. 히스토리 탭 접근

**Expected:**
- 생성 기록 카드들 표시
- 날짜, 제목, 스타일 정보

#### TC-2.2: 히스토리 아이템 클릭
**Steps:**
1. 히스토리 카드 클릭

**Expected:**
- 해당 콘텐츠 상세 표시
- 결과 패널에 내용 로드

#### TC-2.3: 빈 히스토리 상태
**Steps:**
1. 히스토리 없는 상태에서 탭 접근

**Expected:**
- "생성 기록이 없습니다" 메시지
- 시작 유도 안내

### Suite 3: 사용량 패널

#### TC-3.1: 사용량 정보 표시
**Steps:**
1. 사용량 탭 접근

**Expected:**
- 오늘 사용량 표시
- 남은 사용량 표시
- 프로그레스 바

#### TC-3.2: 사용량 제한 경고
**Steps:**
1. 사용량이 한도에 가까울 때 확인

**Expected:**
- 경고 색상/메시지
- 남은 횟수 강조

### Suite 4: 탭 전환

#### TC-4.1: 빠른 탭 전환
**Steps:**
1. 대시보드 → 히스토리 → 사용량 빠르게 전환

**Expected:**
- 각 패널 정상 로드
- 깜빡임 없음
- 이전 상태 유지

#### TC-4.2: 탭 활성 상태 유지
**Steps:**
1. 히스토리 탭 선택
2. 페이지 내 다른 동작 수행
3. 탭 상태 확인

**Expected:**
- 활성 탭 상태 유지됨
