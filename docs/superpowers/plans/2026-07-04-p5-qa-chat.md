# P5 Q&A Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사용자가 처리된 자막/본문과 관련 노트를 근거로 자유 질문에 답변받는 Q&A 채팅을 만든다.

**Architecture:** Flask에 별도 `chat_routes.py` 블루프린트를 추가하고, LiteLLM 호출은 `services/core/ai_service.py`의 얇은 chat helper로 캡슐화한다. 프론트는 `ResultCard`의 dynamic 하위 컴포넌트로 채팅 패널을 붙이며 기존 zustand selector 패턴을 유지한다.

**Tech Stack:** Flask, LiteLLM, pytest, Next.js 16, React 19, TypeScript, Tailwind v4.

---

### Task 1: Backend route and AI helper

**Files:**
- Create: `routes/chat_routes.py`
- Modify: `services/core/ai_service.py`
- Modify: `utils/responses.py`
- Modify: `app.py`

- [ ] **Step 1: Add tests first**
  - `tests/test_chat_routes.py`에 성공, 400 검증, provider error, notes search failure 케이스를 작성한다.

- [ ] **Step 2: Implement route**
  - `/api/chat` POST를 `@require_auth`, `@limiter.limit("20/minute")`로 보호한다.
  - 입력 제한: question 1~500자, context 1~50,000자, history 최대 10턴.
  - `note_index_service.search_notes(question, limit=3)` 실패는 warning만 남기고 계속 진행한다.
  - 검증 오류는 `[채팅 실패]` 400, AI 오류는 `handle_error(str(exc))`로 반환한다.

- [ ] **Step 3: Implement AI helper**
  - `ai_service.create_chat_response(messages, model, max_tokens=1200, temperature=0.2)`를 추가한다.
  - 기존 `_build_completion_kwargs`, `_get_completion`, `_convert_error_message` 패턴을 재사용한다.

- [ ] **Step 4: Register blueprint and safe prefix**
  - `app.py`에 `chat_bp`를 등록한다.
  - `utils/responses.py` 안전 접두어에 `[채팅 실패]`를 추가한다.
