## 1. 전체 레이아웃 & 컬러 시스템

### 레이아웃 구조

```
┌──────────────────────────────────────────────────┐
│  헤더 (48px)                                      │
│  ☰ Insight Engine          사용량 3/20 · ⚙ · 👤   │
├────────────┬─────────────────────────────────────┤
│            │                                     │
│  사이드바    │       중앙 컨테이너 (max-w: 768px)    │
│  (260px)   │                                     │
│            │   ┌─────────────────────────────┐   │
│  + 새 분석  │   │ URL 입력 바 + ⚙ + 생성 버튼   │   │
│            │   └─────────────────────────────┘   │
│  오늘       │                                     │
│   제목1    │   ┌─────────────────────────────┐   │
│   제목2    │   │ 결과 카드 1                    │   │
│            │   └─────────────────────────────┘   │
│  어제       │   ┌─────────────────────────────┐   │
│   제목3    │   │ 결과 카드 2                    │   │
│            │   └─────────────────────────────┘   │
│            │                                     │
└────────────┴─────────────────────────────────────┘
```

### 컬러 팔레트

| 용도 | 색상 | 값 |
|------|------|-----|
| 배경 | 순백 | `#FFFFFF` |
| 표면 (카드, 입력, 사이드바) | 미세한 그레이 | `#F9FAFB` |
| 테두리 | 연한 그레이 | `#E5E7EB` |
| 텍스트 (주) | 거의 검정 | `#111827` |
| 텍스트 (보조) | 중간 그레이 | `#6B7280` |
| 액센트 | 인디고 | `#4F46E5` |
| 액센트 hover | 진한 인디고 | `#4338CA` |
| 액센트 배경 (칩/배지) | 연한 인디고 | `#EEF2FF` |
| 성공 | 녹색 | `#059669` |
| 경고 | 노랑 | `#D97706` |
| 에러 | 빨강 | `#DC2626` |

### 타이포그래피

- 폰트: Pretendard (한글) + Fira Code (코드) 유지
- 본문: 16px, `#374151`, line-height 1.6
- 제목: medium weight (semibold에서 한 단계 가볍게)
- 카드 제목: 20px, semibold
- 메타 텍스트: 13px, `#6B7280`

### 비주얼 원칙

- 글래스모피즘, 그라디언트 버튼, 글로우 이펙트 전면 제거
- 얇은 보더 (`1px solid #E5E7EB`) + 미세한 그림자 (`shadow-sm`) + 넓은 여백
- 장식 최소화, 콘텐츠 자체에 집중

## 2. 헤더

**높이:** 48px (현재 56px에서 축소)

```
┌──────────────────────────────────────────────┐
│ ☰  Insight Engine        사용량 3/20 · ⚙ · 👤 │
└──────────────────────────────────────────────┘
```

- 좌측: 햄버거 메뉴 (사이드바 토글) + "Insight Engine" 텍스트 로고
- 우측: 사용량 텍스트 · 설정 아이콘 · 프로필 아이콘
- 하단: `1px solid #E5E7EB` 보더만 (그림자 없음)
- 프로바이더/모델 선택, 테마 토글, 버전 뱃지 제거 (설정으로 이동)

- 항목 hover 시 삭제 아이콘 표시
- "새 분석" 버튼: 입력 바 초기화
- 기존 `ie_histories` 테이블 데이터 활용

## 4. 중앙 컨텐츠 - 입력부

### 빈 상태 (첫 진입)

결과가 없을 때 화면 중앙에 크게 배치:

```
         YouTube 영상을 블로그로 변환하세요

  ┌────────────────────────────┬───┬───┐
  │ YouTube URL 입력...         │ ⚙ │ → │
  └────────────────────────────┴───┴───┘
```

### URL 입력 바

- 둥근 모서리: `border-radius: 12px`
- 배경: `#F9FAFB`
- focus 시 보더: `#4F46E5` (인디고)
- 우측 ⚙ 아이콘: 설정 팝오버 토글
- 우측 → 버튼: 인디고 배경 `#4F46E5` + 흰색 화살표 아이콘 (유일한 강조색 포인트)
- 결과 생성 후 하단 또는 상단에 고정

### 배치 URL 입력

- 엔터로 URL 추가 시 입력 바 아래에 칩 형태로 나열
- 각 칩에 ✕ 삭제 버튼

### 설정 팝오버 (⚙ 클릭 시)

```
┌─────────────────────────┐
│ AI 모델                  │
│ [Gemini 3 Flash    ▾]   │
│                         │
│ 스타일                   │
│ ○ Blog+SEO  ○ 요약      │
│ ○ 튜토리얼  ○ Q&A       │
│ ○ 앱 아이디어 ○ 요즘IT   │
│ ○ 브런치    ○ 네이버     │
│                         │
│ 길이: [짧게|보통|길게]    │
│ 문체: [대화체 ▾]         │
└─────────────────────────┘
```

- 아래로 펼쳐지는 팝오버
- AI 모델: 드롭다운
- 8개 스타일: 라디오 리스트 (컬러 그라디언트 카드 → 심플 라디오)
- 길이: 세그먼트 컨트롤 (짧게/보통/길게)
- 문체: 드롭다운
- 바깥 클릭 시 닫힘 (자동 닫힘 없음)

## 5. 결과 카드

### 카드 구조

```
┌──────────────────────────────────────────┐
│                                          │
│  AI가 분석한 블로그 제목                    │  ← 20px semibold
│                                          │
│  blog+seo · 1,234자 · 3.2초 · 댓글 포함    │  ← 13px #6B7280
│                                          │
│  ─────────────────────────────────────   │
│                                          │
│  본문 콘텐츠 (마크다운 렌더링)              │
│  ...                                     │
│                                          │
│                          📋 🔗 ⋯  │  ← 액션 버튼
└──────────────────────────────────────────┘
```

### 디자인

- 배경: `#FFFFFF`
- 보더: `1px solid #E5E7EB`
- 그림자: `shadow-sm`
- 메타 정보: 제목 아래 한 줄, `·` 구분자
- 본문: 16px, `#374151`, line-height 1.7

### 액션 버튼 (우측 하단, 항상 표시)

- 📋 복사 (Rich Copy: text/html + text/plain 유지)
- 🔗 공유
- ⋯ 더보기 메뉴: 프롬프트 보기, 마인드맵, HTML 내보내기, 다시 생성
- 아이콘만 작게, hover 시 `#F3F4F6` 원형 배경

### 접기/펼치기

- 제목 클릭 시 본문 토글
- 접힌 상태: 제목 + 메타 라인만 표시

### 검색/필터

- 결과 카드 상단에 검색 바 유지
- `<mark>` 하이라이트 (300ms 디바운스)
- 스타일 드롭다운 필터

## 6. 모달

### 공통 스타일

```
┌──────────────────────────────────┐
│                              ✕   │
│  모달 제목                        │  ← 20px semibold
│  ─────────────────────────────   │
│  콘텐츠                          │
│              [취소]  [확인]       │
└──────────────────────────────────┘
```

- 백드롭: `rgba(0,0,0,0.3)` (blur 제거)
- 모달 카드: `#FFFFFF`, `border-radius: 16px`, `shadow-xl`
- 진입: 아래→위 슬라이드 200ms
- 적용 대상: 설정, 계정관리, 관리자 대시보드, 마인드맵, 프롬프트 뷰어

### 버튼 체계 (3단계)

| 유형 | 스타일 | 용도 |
|------|--------|------|
| Primary | 인디고 배경 `#4F46E5` + 흰 텍스트 | 생성, 확인 등 핵심 액션 |
| Secondary | `#F3F4F6` 배경 + `#374151` 텍스트 | 취소, 보조 액션 |
| Ghost | 배경 없음, 텍스트만 | 링크형 액션 |

모든 버튼 `border-radius: 8px`, 그라디언트 전면 제거.

## 7. 알림/토스트 & 로딩

### 토스트 알림

- 위치: 화면 상단 중앙
- 성공: 좌측 녹색 바 + 메시지
- 에러: 좌측 빨간 바 + 메시지
- 3초 후 자동 사라짐, 위→아래 슬라이드

### 로딩 상태

- 스켈레톤 유지, shimmer 더 은은하게
- 생성 중: "분석 중..." 텍스트 + 미세한 스피너

## 8. 제거 목록

| 항목 | 이유 |
|------|------|
| Dark / Minimal 테마 | Light 단일 통일 |
| `_tokens.css` 다크/미니멀 변수 | 불필요 |
| 테마 전환 토글 (헤더) | 테마 하나만 |
| 글래스모피즘 (`backdrop-filter`, `glass-card`) | 미니멀 방향 |
| 그라디언트 버튼 | 플랫 버튼 대체 |
| 글로우 이펙트 (`shadow-glow`) | 제거 |
| 테라코타 컬러 (`#D4A87A`) | 인디고 교체 |
| 좌우 2단 패널 구조 | 중앙 단일 컬럼 |
| 입력 패널 350px 고정 | 팝오버 전환 |
| 스타일 카드 그리드 (컬러 그라디언트) | 라디오 리스트 |
| `PanelResizeManager.js` | 패널 분할 없음 |
| `ThemeManager.js` (대부분) | 테마 전환 로직 제거 |
| 버전 뱃지 (헤더) | 제거 |
