# 콘텐츠 퓨전 엔진 설계

> 같은 주제의 영상 N개 + AI 자동 검색 외부 소스 + 댓글 심층 분석을 융합하여, 그 주제에 대해 가장 완벽한 1편의 글을 생성하는 기능

## 배경

현재 Insight Engine은 단일 URL → 단일 글, 배치 URL → 각각 글, 합쳐서 생성(단순 자막 결합) 기능을 지원한다. 댓글은 병렬로 요약하여 글 말미에 붙이는 수준이다.

**문제:** 같은 주제의 영상 여러 개를 분석할 때 각 영상의 고유한 인사이트를 살려 통합하지 못하고, 댓글의 풍부한 정보(실제 경험, 반론, 질문)를 충분히 활용하지 못한다.

**해결:** 다단계 파이프라인으로 소스를 수집 → 분석/압축 → 융합하여 최종 1편을 생성한다.

## 아키텍처: 3단계 파이프라인

```
사용자 입력: YouTube URL 2~5개 + 스타일 + 모디파이어
                    ↓
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Phase 1: 소스 수집 (병렬)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ├─ [1a] 영상별 자막 추출 (기존 content_service)
  ├─ [1b] 영상별 댓글 수집 (기존 content_service)
  └─ [1c] 주제 키워드 추출 → 웹 검색 → 외부 소스 크롤링 (신규)
                    ↓
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Phase 2: 분석 & 압축 (병렬)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ├─ [2a] 영상별 핵심 요약 (각 자막 → 구조화된 요약)
  ├─ [2b] 댓글 심층 분석 (인사이트/질문/반론/보충 분류)
  └─ [2c] 외부 소스 요약 (크롤링 결과 → 핵심 정보 추출)
                    ↓
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Phase 3: 융합 & 생성
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  └─ 통합 프롬프트로 최종 글 생성
         ├─ 본문: 영상 인사이트 융합 + 댓글 자연 반영
         ├─ FAQ 섹션: 댓글 기반 자주 묻는 질문
         ├─ 팩트체크: 댓글이 지적한 오류 인라인 표시
         └─ 출처 표시: 영상별 + 외부 소스 출처
```

### 설계 원칙

- Phase 1~2는 최대한 병렬 실행 (기존 ThreadPoolExecutor 패턴 확장)
- 각 Phase 결과는 SQLite 캐시 (기존 cache_service 활용)
- Phase 3만 순차 (Phase 1~2 결과 필요)

## API 엔드포인트

### `POST /api/generate-fusion`

**요청:**
```json
{
  "urls": ["https://youtube.com/watch?v=A", "...B", "...C"],
  "style_id": "blog_seo",
  "modifiers": {"length": "long", "writing_style": "explanatory"},
  "provider": "gemini",
  "model": "gemini/gemini-3-flash-preview",
  "enable_web_research": true,
  "enable_deep_comments": true
}
```

**응답:**
```json
{
  "title": "...",
  "content": "...(마크다운, 댓글 인사이트 본문 내 포함)...",
  "html": "...",
  "sections": {
    "faq": "...(댓글 기반 FAQ)...",
    "fact_checks": ["영상A에서 X라고 했으나, 댓글에서 Y라는 지적이 다수"],
    "sources_used": [
      {"type": "youtube", "title": "...", "url": "..."},
      {"type": "web", "title": "...", "url": "..."}
    ]
  },
  "fusion_meta": {
    "videos_analyzed": 3,
    "comments_analyzed": 150,
    "web_sources_found": 4,
    "total_tokens": 12500,
    "processing_time": 25.3
  },
  "usage": {...}
}
```

### 기존 엔드포인트와의 관계

| 엔드포인트 | 용도 | 변경 |
|-----------|------|------|
| `POST /generate` | 단일 URL → 단일 글 | 변경 없음 |
| `POST /generate-batch` | N URL → N 글 | 변경 없음 |
| `POST /api/generate-multi` | 1 URL × N 스타일 | 변경 없음 |
| `POST /api/generate-fusion` | N URL → 융합 1편 | **신규** |

**사용량:** 1회 차감

## 신규 서비스

### 1. 웹 리서치 서비스 (`services/web_research_service.py`)

주제 키워드 → 웹 검색 → 관련 기사/블로그 크롤링 → 요약

**흐름:**
1. 영상 자막들 → AI에게 핵심 키워드 3~5개 추출 요청
2. 키워드로 DuckDuckGo 검색 (requests + BeautifulSoup)
3. 상위 3~5개 기사 본문 크롤링 (trafilatura 라이브러리)
4. 각 기사를 AI로 요약 (병렬) → 구조화된 외부 소스 데이터

**제한:** 크롤링 최대 5개, 실패 시 건너뜀, 로봇 차단 사이트 건너뜀

### 2. 댓글 심층 분석 서비스 (`services/comment_analyzer_service.py`)

AI 프롬프트로 댓글을 4가지로 분류:

| 분류 | 설명 | 활용 |
|------|------|------|
| 인사이트 | 영상에 없는 추가 정보, 실제 경험 | 본문에 자연스럽게 녹여내기 |
| 질문 | 시청자가 자주 묻는 궁금증 | FAQ 섹션 자동 생성 |
| 반론/지적 | 영상 내용에 대한 반대 의견, 오류 지적 | 팩트체크 표시 |
| 감상 | 단순 호응, 감상 | 기존처럼 요약에만 사용 |

**입력:** 댓글 리스트 (좋아요 순 상위 50개/영상)
**출력:** `{"insights": [...], "questions": [...], "fact_checks": [...], "sentiments": [...]}`

### 3. 퓨전 프롬프트 (`prompts/styles/fusion.py`)

융합 전용 지시문:
- 각 영상의 고유한 관점을 살려 통합, 중복 제거
- 댓글 인사이트는 "시청자들의 실제 경험에 따르면..." 형태로 본문에 녹여내기
- FAQ 섹션은 글 말미에 별도 구성
- 팩트체크는 인라인 표시
- 외부 소스 정보는 출처 표시 포함

## 프론트엔드 UI

### 진입점: 3번째 탭 추가

기존 "개별 분석" / "합쳐서 분석" 토글에 "퓨전 분석" 탭 추가:

```
[개별 분석]  [합쳐서 분석]  [퓨전 분석]
```

퓨전 분석 선택 시 추가 옵션:
- ☑ 웹 리서치 (관련 기사 자동 검색)
- ☑ 댓글 심층 분석 (FAQ, 팩트체크 포함)

### 결과 카드 확장

퓨전 전용 추가 요소:
- 메타칩: 영상 수, 댓글 수, 외부 소스 수
- FAQ 섹션 (접을 수 있는)
- 참고 소스 섹션 (접을 수 있는)
- 팩트체크 인라인 표시

### 진행 상태 표시

다단계 파이프라인 진행 상태 실시간 표시:
```
● 자막 수집 중... (2/3)
○ 댓글 분석 대기
○ 웹 리서치 대기
○ 최종 글 생성 대기
```

## 에러 처리: Graceful Degradation

| 실패 상황 | 처리 |
|-----------|------|
| 웹 리서치 실패 | 영상+댓글만으로 생성 |
| 댓글 수집 실패 | 영상+외부소스만으로 생성 |
| 특정 영상 자막 추출 실패 | 나머지 영상으로 진행, 실패 알림 |
| 외부 소스 크롤링 차단 | 해당 소스 건너뜀 |

## 제약 사항

- 영상 수: 최소 2개, 최대 5개
- 댓글: 영상당 최대 50개 (좋아요 순)
- 외부 소스: 최대 5개 기사
- 1개 URL이면 기존 `/generate` 사용 유도

## 신규 의존성

- `trafilatura`: 웹 기사 본문 추출 (newspaper3k 대안, 유지보수 활발)
- `duckduckgo-search`: DuckDuckGo 검색 API (API 키 불필요)
