## 주요 인사이트

### 개선에 성공한 패턴
- **Why 설명 추가**: 단순 지시보다 이유를 설명하면 clarity 향상 (R5: "AI 검색 엔진이 첫 문장을 인용 후보로 우선 처리하기 때문")
- **구체적 예시 포함**: Few-shot 예시가 실질적으로 example_quality와 구조 이해에 기여 (R1: +6점)
- **목적 명시적 나열**: GEO 인용 조건을 번호 목록으로 나열하면 style_specificity 향상 (R9: +1점)
- **분류 기준 추가**: 엔티티 태그 3범주 분류가 constraints 명확성에 기여 (R3: +1점)

### 개선이 실패한 패턴
- **추가 규칙 삽입**: 기존 규칙과 충돌하거나 중복되는 새 규칙은 점수 하락 유발
- **예시에 없는 내용 요구**: 예시(상세 분석 섹션 없음)와 템플릿 간 불일치가 example_quality 감점 요인
- **길이/수량 제한 세분화**: 이미 명확한 제약을 더 세분화하면 오히려 혼란 증가
- **면책/전제 조항**: 입력 처리 관련 부가 조건은 프롬프트를 복잡하게만 만듦

### 평원(Plateau) 분석
R9 이후 93점에서 14라운드 연속 정체. 평가자가 일관되게 지적한 미해결 이슈:
1. **예시-템플릿 불일치**: 상세 분석 섹션이 예시에 없어 example_quality 상한이 11~12점 수준
2. **검증 메커니즘 부재**: 자막 근거 명시(타임스탬프 등) 규칙이 없음
3. **섹션 길이 명세 부재**: 각 섹션별 문장 수/글자 수 제한 미정의

이 3가지를 동시에 해결하면서 기존 규칙과 충돌하지 않는 변경이 필요하나, 단일 소규모 변경으로는 달성하기 어렵다고 판단.

## 권장 후속 작업

1. **예시 완성**: 상세 분석 섹션 2개를 예시에 추가 → example_quality 17점 → 19점 가능성
2. **일괄 리팩토링**: 예시 완성 + 섹션 길이 명세 + 검증 규칙을 한 번에 반영 (단일 변경 제약 없이)
3. **목표 점수 95+**: 현재 평원 원인이 예시 불완성에 있으므로 R1 이후 예시 확장이 가장 효과적
