## 성공한 변경 사항 (세션 2)

### 복합 변경 (91→92):
- `관련 자료/링크 (없으면 섹션 생략)` → 필수 요소와 출력 형식 모두 일치
- 섹션 생략 조건부 설명 (`(언급된 항목이 없으면 이 섹션 전체 생략)`) 출력 형식에 추가
- 키워드 규칙: `정확히 5개 (고유명사·핵심 개념 우선, 본문 등장 단어, 중복 없이)`
- 토픽 병합: `7개 이상이면 유사한 것 병합해 6개 이내 압축`
- 두 번째 예시 추가: 미니멀리즘 (도구 없음, 자료 있음 케이스)
- 예시에 전문 용어 괄호 설명 시연: `LLM(대규모 언어 모델)`
- 섹션 생략 규칙에 추측 금지: `자막에 없는 사실·수치·URL·인물은 추측하거나 추가하지 말 것`

## 실패 패턴 분석 (세션 2 추가)

1. **새 규칙 추가 + 예시 미반영**: 새로운 처리 규칙 추가 시 예시에 해당 케이스가 없으면 example_quality 하락
2. **에피소드 요약 구조화 시도**: "2~3줄이면서 3역할 구조" → clarity 모호성 증가로 오히려 하락
3. **자가 검증 힌트**: "structure 긴장감" 지적으로 하락
4. **두 번째 예시 내용**: 수치가 많은 예시(수면 과학) → "환각 유발 우려" 지적으로 하락

## 개선 방향 (미완)

평가자가 지속적으로 언급했지만 구현 시 점수 하락이 발생한 과제:
- 에피소드 요약 3줄 구조 명시 (주제·핵심·결론) — clarity 하락 발생
- 제목 부재 처리 규칙 — example_quality 하락 발생 (규칙에 맞는 예시 미비)
- 토픽 7개 이상 압축 예시 — 시도 안 함 (복잡도 우려)
- 링크/URL 없을 때 표기 규칙 — 시도 안 함
