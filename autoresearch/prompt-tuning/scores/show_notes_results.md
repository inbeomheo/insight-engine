## 성공한 변경 사항 (R1~R3)

### R1: 예시 완성
- 3번째 토픽 (`**3. AI 에이전트의 한계와 주의사항**`) 추가
- 도구 테이블에 `AutoGPT` 항목 추가
- 핵심 키워드 섹션 추가

### R2: 환각 방지
- `관련 자료/링크 (추측 가능한 경우)` → `관련 자료/링크 (입력에 명시된 경우만 포함, 없으면 생략)`

### R3: 구조화 명확성
- `목차 형태로 토픽 나열 (3~6개, 등장 순서 기준)` 추가
- `각 토픽은 1~2줄 요약` 명시

## 실패 패턴 분석

평가자가 지속적으로 요청했지만 추가 시 점수가 하락한 변경들:

1. **섹션 처리 규칙 통일**: "없음 표기 vs 섹션 생략" 충돌 지적 → 통일 시도마다 점수 하락
2. **출력 검증 체크리스트**: 별도 섹션으로 추가하면 복잡성 증가로 오히려 감점
3. **조건부 섹션**: 출력 형식에 `관련 자료` 섹션을 추가하면 점수 하락
4. **분류 컬럼**: 테이블 복잡도 증가로 -6점 (가장 큰 하락)
5. **예시 확장**: 두 번째 예시 추가는 도움이 되지 않음
