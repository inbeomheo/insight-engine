## 핵심 개선 사항 (채택된 변경)

1. **출력 순서 완전 명시**: `강의 소개 → 강의 개요 → 학습 목표 → 본문 → 핵심 정리 → 실습 → 퀴즈 → 다음 단계` 전체 흐름 명시 (+3점)
2. **전환 문장 의무화**: Section 2부터 앞 섹션 연결 전환 문장 한 줄 필수 (+1점)
3. **예시 완성형 확장**: 전환 문장, 실습 과제, 퀴즈, 다음 단계 학습까지 포함한 완결형 예시 (+2점)
4. **출력 언어 한국어 고정 명시**: 기술 용어 원문 병기 허용 규칙 (+1점)
5. **필수 검증 체크리스트**: 5개 항목 체크리스트 (모두 충족 필수) (+1점)
6. **예시 도메인 중립성 명시**: "형식 참고용이며 도메인은 자막에 맞춤" (+0점, 안정화)

## 주요 교훈 (실패한 시도)

- **과도한 제약 추가는 역효과**: 섹션 수 규칙, 분량 상한, 자막 직접 언급만 반영 등 세분화된 제약은 오히려 점수 하락 (-3~-4점)
- **퀴즈 템플릿 세분화 실패**: 정답/해설 포함, [개념]/[응용] 라벨 구분 → 일관성보다 복잡도 증가로 점수 하락
- **Section 3 예외 처리 규칙**: 자막 부족 시 예외 규칙이 "자막 없는 내용 금지"와 충돌로 낮은 평가
