## 핵심 개선 내용 (최종 적용 변경)

### 1. 목표 섹션 — 플랫폼 명시 + 독립 감상 조건 (R18, +1점)
```
긴 YouTube 영상에서 독립적으로 감상 가능한 핵심 구간 3~5개를 추출하고,
YouTube Shorts/Instagram Reels용 60초 이내 스크립트를 만들어주세요.
각 클립은 원본 영상을 보지 않아도 혼자 이해 가능해야 합니다.
```

### 2. 60초 기준 구체화 — 문장 수 + 낭독 시간 (R7, R19)
```
- 60초 이내로 압축 가능한 구간 (스크립트 총 5~8문장, 목표 낭독 시간 45~55초)
```

### 3. 후킹 유형 가이드 (R5)
```
- 첫 3초에 시청자를 붙잡을 후킹 문구 필수
  (유형: 질문형 "~한 적 있나요?", 반전형 "사실 ~가 아니에요", 수치형 "~% 사람들이 모르는")
```

### 4. 구어체 어미 예시 (R17)
```
- 구어체로 자연스럽게 작성 (읽는 글이 아니라 말하는 글 — "~죠", "~잖아요", "~거든요" 같은 구어 어미 사용)
```

### 5. 타임스탬프 추정 규칙 (R8)
```
**타임스탬프**: 약 MM:SS ~ MM:SS
(자막 흐름상 주제 전환 시작점 ~ CTA 직전, 불확실하면 가장 근접한 구간으로 표기)
```

### 6. 오버레이 역할 명시 (R16)
```
**추천 자막/텍스트 오버레이** (각 12자 이내, 1~2개)
- (역할: 후킹 강화/핵심 요약/CTA 보조 중 하나, 키워드 또는 대비 구조 권장)
```
