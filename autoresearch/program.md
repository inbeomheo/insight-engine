# 프롬프트 품질 자동 튜닝 프로그램

## 개선 방향

### 원칙
- 프롬프트의 의도/스타일 특성은 유지
- 구조적 완성도만 개선 (내용 변경 최소화)
- base.py는 수정하지 않음

### 개선 항목 (우선순위순)

1. **금칙어 방지 규칙 명시**: 스타일 프롬프트에 금칙어 목록과 댓글 규칙이 명시되지 않은 경우 추가
2. **Few-shot 예시 추가**: 예시가 없는 프롬프트에 해당 스타일의 좋은 출력 예시 추가
3. **출력 언어 명시**: 한국어 작성 지시가 없는 프롬프트에 추가
4. **구체적 수치 지시**: "적절히", "충분히" 같은 모호한 표현을 구체적 수치로 교체
5. **CoT 단계 보강**: 작성 순서/가이드가 없는 프롬프트에 단계별 지시 추가

### keep/revert 기준
- 개선 후 총점이 이전보다 높으면 keep
- 총점이 같거나 낮으면 revert
- 프롬프트 길이가 2배 이상 늘어나면 revert (과도한 팽창 방지)
